# 筒车 TONG CHE — 机构复刻 No.05

王祯《农书》筒车:立式大水轮,轮缘斜绑 26 只竹筒,下部浸水兜水、上行带水、
顶部自动倾入笧槽——「随流自有得,加工不假人」。本站三维装配 + 充水运动学
仿真,流量按公式可验算,B 键查看复原总图。

## 机构与验算

```
尺寸(宋营造尺按 0.3 m):
  大轮   径一丈四尺       R = 2.10 m(双缘 + 24 辐)
  竹筒   26 只等分 13.85° 口径 0.08 · 长 0.52 · 口迎水上翘 25°
  浸深   0.35 m(轮心 y=2.25,水面 y=0.5)→ 浸水半角 34°
  笧槽   长 1.3 · 宽 0.36,位于顶部 +x 侧(y=3.72)

单筒满水  V = π·0.04²·0.42·0.85 = 1.79 L(有效容积系数 0.85)

流量      Q = n·V·ω/2π
  常流   ω = 0.42 rad/s(4.0 转/分)→ Q = 3.11 L/s
  急流   ω = 0.62 rad/s(5.9 转/分)→ Q = 4.59 L/s
  倾倒频率 = n·ω/2π = 3.4 ~ 6.1 次/s

充水模型(α 自底部顺时针量):
  326°→346° 入水线性充水 → 346°..34°(经 0°)水下满 →
  34°..165° 带水上行 → 165°..195° 顶部线性排空 → 195°..326° 空筒回落
```

**载入期自检**:mech.js 在启动时模拟 30s 常速运转,实测倾倒水量与
Q 公式偏差 > 8% 即拒绝启动(boot 横幅)。运行期 FLOW 面板用 3s 滑窗
实时对照公式值。

筒口朝向 = 切向(顺时针前进方向)上翘 25°,在底部恰迎上游来水,在顶部
恰朝 +x 倒入笧槽——同一固定绑扎角自然完成「迎水/倾泻」两个动作。
